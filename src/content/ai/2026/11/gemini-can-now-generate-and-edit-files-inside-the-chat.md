The Gemini app can now generate, preview, and edit files directly inside the chat, so a document, a PDF, or a slide deck can be produced and revised without leaving the conversation. The capability is available to all users in all languages where the Gemini app is available.

## What each platform supports

PDF preview and editing works on both the web and mobile versions of the app. The other listed formats are web-only: Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code.

## Why it matters in production

Keeping the draft in the chat means the document and the conversation that shaped it stay in one place. Refinement happens on the same surface, because Gemini can revise a file it has generated. The platform split is where the limits sit: PDF work is available on the web and on mobile, while the spreadsheet, slide, Markdown, TXT, and code formats remain on the web.

## What to do

Expand a file to full screen to type edits directly. Highlight a passage to ask questions about it. Ask Gemini to refine the file when the draft is close but not finished.
