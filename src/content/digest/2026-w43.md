The theme this week is boundaries. An agent is not secure because the model refuses; it is secure
because the tool cannot do more than the request allows. A gateway is not secure because it has a
policy page; it is secure because the caller cannot route around it. A supply-chain response is not
finished when the package is removed; it is finished when the identity is rotated.

## Lead

### [Agentic AI changes the threat model, not just the prompt](/ai/agentic-threat-model/)

The model is the planner, not the security boundary. Once tools are involved, the assets that
matter are tool identity, context, and side effects. The post includes a review checklist for a
new agent and the uncomfortable question to ask before adding another tool.

## Security

### [The first 60 minutes of a supply-chain incident](/security/supply-chain-first-60-minutes/)

A practical order of operations: freeze deploys, snapshot evidence, revoke the highest-reach
credentials, scope every install, then rebuild from a clean cache. The checklist is designed to be
usable while the incident channel is noisy.

### [Securing LLM gateways: a production checklist](/security/securing-llm-gateways/)

Identity, request policy, data handling, egress, observability, failure behaviour, supply chain,
and incident readiness. Updated this week with egress and token-scope checks.

## AI

### [Open-weight models: the bill arrives after the benchmark](/ai/open-weight-models-economics/)

## Engineering

### [Platform engineering learning path: what to learn, in what order](/engineering/platform-engineering-learning-path/)
